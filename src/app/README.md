# app

Единственное место, где фичи соединяются друг с другом: здесь читаются настройки и собираются реализации интерфейсов из `core`.

## Что внутри

| Файл | Содержимое |
|---|---|
| `config.ts` | чтение и проверка конфига, загрузка `.env`, чтение секретов |
| `compose.ts` | общая сборка; здесь подключается детектор зон (тесты могут подменить его через `makeDetector`) |
| `market-analysis.ts` | собирает уровни, EMA, волны и структуру в `MarketAnalysis` для детектора |
| `run-loop.ts` | цикл бэктеста: часы, фандинг, свеча, движок |
| `run-backtest.ts`, `backtest.ts` | прогон и его командная строка |
| `run-live.ts`, `live.ts` | бумажный режим |
| `notify-test.ts` | проверка всех сообщений Telegram |

## Настройки

`loadConfig(path?)` читает JSON, по умолчанию `config/default.json`. Неизвестное поле или неверное значение останавливает запуск с перечнем всех ошибок. Для эксперимента скопируйте файл и передайте его через `--config`. Сам `default.json` зафиксирован тестом: его изменение меняет результаты всех бэктестов.

`requireSecret(name)` возвращает секрет или бросает ошибку с именем переменной. Секрет запрашивается там, где используется, поэтому бэктест через сессии не требует ключа. Переменная, заданная в системе, важнее значения из `.env`.

Секция `baseline` нужна только `RandomSideAdvisor`.

## От чего зависит

От всех фич. Фичи от `app` не зависят.

## Как тестируется

`tests/app/`: конфиг, сквозные прогоны, цикл `live`. Сеть и настоящий `.env` не используются.
