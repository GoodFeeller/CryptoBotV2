# market-data

Данные Bybit для бота: параметры монет, свечи и фандинг. Реализует интерфейс `MarketData` из `core`. Использует только публичный API, ключи не нужны.

## Что внутри

| Файл | Содержимое |
|---|---|
| `bybit-client.ts` | запросы к API v5, листание страниц, повторы при сбоях |
| `candle-store.ts` | кеш свечей и фандинга в `data/`, файлы по месяцам |
| `bybit-market-data.ts` | `BybitMarketData`: кеш + API |
| `clamped-market-data.ts` | `ClampedMarketData`: запрет получать данные новее часов |

## Что принимает и отдаёт

`BybitMarketData` принимает клиент API, кеш и функцию текущего времени. Отдаёт методы `MarketData`, а для отчёта ещё `dataGaps()`.

`ClampedMarketData` оборачивает любой `MarketData` и часы. Движок и детекторы должны получать только её.

## Правила

- **Закрытые свечи:** наружу и в кеш попадают только свечи, закрытые к текущему моменту и к `endAt`.
- **Кеш:** закрытый период не запрашивается повторно. Повреждённая строка пропускается, а свеча запрашивается заново.
- **Отсутствующие свечи** запоминаются в `missing.jsonl`, чтобы не запрашивать их снова. Свеча, закрытая меньше минуты назад, не запоминается: биржа могла её ещё не опубликовать.
- **Дыра в данных** это пропуск между двумя свечами. Значения не выдумываются.
- **Сбои:** сеть и коды 10000, 10006, 10016 повторяются до 5 раз с паузами 0.5, 1, 2, 4, 8 с. Остальные коды сразу становятся ошибкой.

## От чего зависит

Только от `core`.

## Как тестируется

`tests/features/market-data/`, без сети: ответы API подменены.
