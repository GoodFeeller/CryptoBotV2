# risk

Защита счёта от просадки. Реализует интерфейс `RiskGate` из `core`.

## Что принимает и отдаёт

`DrawdownGate` принимает `maxDrawdownHaltPct`. Движок передаёт ему капитал на каждом шаге через `update`.

- `canOpen()` отвечает, можно ли открывать новые сделки.
- `availableLoss(equity, exposures)` отвечает, сколько ещё можно потерять в USDT. Это значение в процентах от баланса получает Claude.

```text
допустимая потеря = капитал − пик × (1 − предел) − потери при стопах открытых сделок и ордеров
```

## Правила

- Просадка считается от пика `Equity.total`, то есть вместе с незакрытым результатом.
- Запрет сам не снимается: в бэктесте он действует до конца прогона, в `live` до перезапуска.
- Предела на одну сделку нет: Claude может поставить на сделку весь запас.

Проверка решения советника и расчёт объёма лежат в `core/trade-rules.ts`: они нужны движку при любом советнике.

## От чего зависит

Только от `core`.
