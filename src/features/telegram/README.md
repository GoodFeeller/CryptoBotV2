# telegram

Сообщения о сделках. Реализует интерфейс `Notifier` из `core`.

## Типы сообщений

| Тип | Содержание | Картинка |
|---|---|---|
| Открыта сделка | монета, лонг/шорт, сигнал, вход, стоп, тейк, причина | да |
| Закрыта сделка | монета, лонг/шорт, результат в USDT и R, причина закрытия, сигнал, вход, стоп, тейк, выход | да |
| Сделка отредактирована | монета, «было → стало» по изменившимся полям, причина | нет |
| Ошибка | где, что случилось, что бот сделал дальше | нет |

## Настройка

`TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в `.env`, чатов может быть несколько через запятую. Проверка: `npm run notify-test` отправляет все 4 типа с пометкой «тест».

## Сбои

До 3 повторов, на 429 ожидание `retry_after`. После этого запись в лог: торговля не останавливается. Недоступный чат не мешает остальным. Если картинка не построилась, сообщение уходит текстом.

`NullNotifier` используется в бэктесте.

## От чего зависит

Только от `core`.

## Как тестируется

`tests/features/telegram/`, без сети. Настоящая отправка проверяется через `notify-test`.
