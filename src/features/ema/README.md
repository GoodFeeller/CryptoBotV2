# ema

Положение EMA в заданный момент. Это подсказка, куда может пойти цена, когда она подходит к уровню. С уровнями модуль пока не связан, в логике бота не участвует.

## Что принимает и отдаёт

`emaSnapshot(candles, at, options)` получает свечи одного таймфрейма и момент времени. Использует только свечи, закрытые к этому моменту, поэтому в бэктесте не заглядывает в будущее. Отдаёт:

- для каждой EMA: значение, с какой стороны цена (`priceSide`), насколько далеко в ATR (`distanceAtr`) и наклон (`slope`: растёт или падает по сравнению со значением `slopeBars` свечей назад);
- `stack`: `up`, если быстрые EMA выше медленных по порядку (20 > 50 > 200), `down` наоборот, `mixed` в остальных случаях;
- `close`: закрытие последней закрытой свечи. На дневке это вчерашнее закрытие, а не текущая цена.

Если свечей меньше `warmupFactor` × самый длинный период, отдаёт `{ ok: false, reason: 'not_enough_candles' }`, а не неточное значение.

`computeEma(values, period)` считает EMA по ряду. Начальное значение: простое среднее первых `period` значений.

## Настройки

Секция `ema` в `config/default.json`: периоды 20, 50, 200, таймфреймы 1h и 1d, наклон за 5 свечей, ATR за 14 свечей, история не меньше 3 × период (600 свечей для EMA 200).

## Как посмотреть

```bash
npm run ema -- BTCUSDT,ETHUSDT 2026-10-31T13:16Z
```

Печатает положение EMA на этот момент, чтобы сверить с EMA на графике биржи. Без даты берётся текущий момент, без монет все монеты из конфига.

## От чего зависит

Только от `core`.

## Как тестируется

`tests/features/ema/` на синтетических свечах: значения EMA, сторона цены, расстояние в ATR, наклон, расположение, отказ без истории и то, что будущие и незакрытые свечи не используются.
