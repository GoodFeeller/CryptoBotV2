# chart

Картинка сделки для Telegram. Реализует интерфейс `ChartRenderer` из `core`.

## Что принимает и отдаёт

Получает монету, сторону, свечи, цены входа, стопа и тейка, у закрытой сделки ещё точку выхода. Отдаёт PNG.

Шкала цены включает все линии, поэтому стоп и тейк видны, даже если далеко от свечей. Если свечей нет или цены совпадают, картинка всё равно строится.

## От чего зависит

От `core` и `@resvg/resvg-js`. Для подписей нужен системный шрифт.

## Как тестируется

`tests/features/chart/`: сигнатура PNG и содержимое SVG. Как картинка выглядит, проверяется глазами через `npm run notify-test`.
