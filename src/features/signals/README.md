# signals

Поиск рыночных ситуаций. Реализует интерфейс `SignalDetector` из `core`. Сейчас здесь только заглушки: настоящие уровни и сигналы появятся на следующих этапах.

## Что принимает и отдаёт

Детектор получает монету, время и закрытые свечи. Он отдаёт `Situation`: тип, уровни и индикаторы. Стороны, цены входа, стопа и тейка в ситуации нет, их выбирает Claude.

| Детектор | Назначение |
|---|---|
| `EveryNCandlesDetector` | ситуация каждые N свечей, чтобы прогнать конвейер целиком |
| `ScriptedSignalDetector` | ситуации из списка, только для тестов |

У обоих `isPlaceholder = true`, поэтому вердикт отчёта по ним всегда `N/A`.

## Как добавить настоящий детектор

Создайте класс с `isPlaceholder = false` и подключите его в `src/app/compose.ts`. Цены индикаторов называйте с префиксом `price:`, например `price:ema50`: так они попадут в обезличенную шкалу. Если забыть префикс, в запрос утечёт реальная цена монеты. В `kind` нельзя указывать тикер или дату.

## От чего зависит

Только от `core`.
